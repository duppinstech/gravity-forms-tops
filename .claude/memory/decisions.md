# Recorded Project Decisions

- Preserve PHP 7.4 and WordPress 6.2 compatibility unless a support-policy change is explicitly approved.
- Keep this plugin focused on the Gravity Forms to TowX integration; do not add unrelated product features.
- Keep release packaging in GitHub Actions and use version tags matching `v*`.
- Treat credentials and customer submission data as sensitive; consult `SECURITY.md` for exact current storage behavior.
- Record durable decisions here with date, context, and consequence. Do not use this file as a substitute for an issue tracker.
- 2026-10-14: Adopted dev-only Composer tooling (PHPUnit 9.6, PHPCS with WordPress-Extra minus formatting sniffs, PHPCompatibilityWP 7.4+). Formatting sniffs (Yoda, alignment) stay off to avoid a whole-codebase reformat; enable them only as a dedicated formatting change.
- 2026-10-14: `get_form_settings()` returns secrets as stored (encrypted); `get_runtime_form_settings()` decrypts for TowX calls only. Consequence: never render runtime settings.
- 2026-10-14: TowX vehicle lists are cached in transients (1 hour default) keyed by a salted hash of API base + credentials.
- 2026-10-14 (superseded same day): Request-log rows were retained indefinitely.
- 2026-10-14: Request-log rows are deleted after 90 days by default (owner: "whatever you suggest"; 90 covers a monthly billing cycle with margin). Configurable, 0 keeps forever. Gravity Forms entries are never deleted by this plugin.
- 2026-10-14 (superseded same day): Visitors saw TowX error text.
- 2026-10-14: Visitors see a generic error plus the contact line; signed-in staff who can open the log see the real error and a link; error emails link to the log. A custom template with {error} can still show it.
- 2026-10-14: The ⚡ marker on public Make / Model / Color labels stays.
- 2026-10-14: Adopted the shared GitHub updater standard v1.0.0 (docs/github-updater-standard.md). This repo holds the reference implementation; other plugins copy the class verbatim with a renamed class. Private repositories are out of scope.
- 2026-10-14: Every change goes through the department review board (security, legal, finance, product, QA, docs/support agents) after development and before merge or release.
- 2026-10-14: Sales model: payment is taken before the plugin is delivered or installed. No license keys or activation in the plugin. Releases are public on GitHub, so the code itself is not access-controlled (GPL).
- 2026-10-14: Copyright holder of record is Duppins Technology; Odell Duppins is the author.
- 2026-10-14: Support channel is support@duppinstech.com (also the security contact and the .pot bug-report address). No response-time promise.
- 2026-10-14 (client name superseded 2026-10-18): OWNERSHIP.md stayed in the repo and out of the release ZIP. It no longer names a client.
- 2026-10-14: Tags matching v* are protected by a repository ruleset (only admins create; no update or delete).
- 2026-10-16: Updater standard v1.1.0 (R7): release notes include the version's changelog section (CHANGELOG.md or readme.txt) via bin/release-notes.sh; CI runs it on every PR. Class behavior unchanged.
- 2026-10-18: Plugins screen presentation uses the Duppins plugin-info standard v1.0.0 (`GF_Tops_Plugin_Info`). Settings links to Forms → Settings → TOPS and is shown to users with `manage_options` (the class default). There is no public Help URL, so the Help link is omitted; the setup guide stays in readme.txt. Support stays `mailto:support@duppinstech.com`. Sponsor stays the class default. Banner and icon are generated artwork. Product screenshots are added only from a real Gravity Forms admin screen.
- 2026-10-18: Release ZIPs are verified offline with `gh attestation verify gravity-forms-tops.zip -R duppinstech/gravity-forms-tops`. The in-plugin updater does not check attestations or checksums until the shared updater standard does.
- 2026-10-18: Withdrawn the same day: treating this plugin as a private, not-for-sale tool. Distribution stays the 2026-10-14 public GPL model. The TowX Product is a setting, default TOPSLink, not a reason to limit who can use the plugin.
- 2026-10-18: API product is chosen under Forms → Settings → GF TowX Integration (the tab was labeled TOPS on this date). Missing, blank, or invalid values send TOPSLink. The upgrade routine does not write this setting, so an update does not replace a saved custom product and does not store TOPSLink on sites that have never set one. QA (`apiqa.towxchange.net`) is down; only production is working. Do not default new installs to QA.
- 2026-10-19: The public product name is GF TowX Integration. It connects a Gravity Forms form to TOPS by TowXchange. Duppins Technology is not affiliated with Rocketgenius or TowXchange. The folder, text domain `gravity-forms-tops`, add-on slug `gravityformstops`, and saved settings stay unchanged. A draft name, Callpost, was set aside the same day.
- 2026-10-19: Do not ship a sample Gravity Forms form.
- 2026-10-19: The owner closed the employer-IP / work-account location question without a counsel review. Copyright holder of record stays Odell Duppins Jr, doing business as Duppins Technology.
- 2026-10-19: Warranty is AS IS, matching the GPL. Payment, when charged, covers delivery, setup and support, not the code and not TowX API access. Refund terms were not stated.
- 2026-10-19: TowX API use is for TowXchange customers who have an existing agreement and credentials issued by TowXchange. Credentials stay per form and are sent on the request, which TowX documents as the method. A custom API host keeps the existing warning and is not restricted to `*.towxchange.net`.
- 2026-10-19: Failure emails keep the redacted request, the TowX response, and the log link. The visitor message when models cannot load stays "Choose the make again to retry."
- 2026-10-19: Contributions use the Developer Certificate of Origin 1.1 (`Signed-off-by` in CONTRIBUTING.md and DCO). No contributor license agreement was added. Public docs in this repository name GF TowX Integration and do not name other products.
